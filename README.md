# 抖音·破茧模式（模拟人生系统）
> 打破信息茧房｜从「算法定义我」到「我选择成为谁」

## 项目介绍
抖音内嵌式**主动身份选择系统**，面向想学习 AI Coding / 考研 / 深度阅读却沉迷娱乐内容的用户，通过「模拟人生」卡片重构信息流，零摩擦实现自我提升。

## 核心特性
- 🚀 **刷到即用**：信息流内插入身份卡片，双击一键切换人生
- 🎭 **身份自选**：Coding达人 / 考研战神 / 深度阅读者等角色
- 🎮 **模拟成长**：后台属性加减，不干扰刷视频体验
- 🔔 **正向提醒**：同伴邀请式提示，拒绝说教
- 📈 **长效留存**：运势签 / 人生审计 / 身份晋升

## 核心功能
1. **身份卡片**：3秒预览视频，先尝后选，支持自定义标签
2. **专属信息流**：85%目标内容 + 15%放松内容
3. **防偏离干预**：连续偏离触发三选一模式
4. **数值系统**：代码力 / 专注值 / 学习力等隐形成长
5. **同频社区**：同身份评论可见，打造静谧自习室

## 技术理念
- AI Native 创业思路：先验证需求，再做产品
- Agentic Coding 高效迭代
- 无入口、零学习成本、沉浸式体验

## 数据指标
- 卡片双击激活率
- 次日/7日留存
- 目标内容时长占比
- 月度角色续约率
